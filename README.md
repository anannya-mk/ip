# Nova

Nova is a command-line task manager with a sarcastic streak. It keeps track of todos, deadlines and events, and saves them between sessions.

- [User guide](https://anannya-mk.github.io/ip)
- [Download the latest release](https://github.com/anannya-mk/ip/releases)

To run it, install Java 25, download `nova.jar` and run `java -jar nova.jar`.
